## JPA Mastery 1.0.0

Erstes öffentliches Release der interaktiven JPA-Lernplattform für DBI/NVS (HTL Leonding, 2025/26).

### Live-App

**[JPA Mastery starten](https://ixi-enki.github.io/DBI_2025_26_jpa_lernen/)**

- 89 interaktive Aufgaben in 8 Modulen
- Sofort im Browser nutzbar — keine Installation
- Validierung, Fortschritt, Cheat Sheet und Wiederholungsmodus
- Ausgerichtet auf DBI/NVS-Lehrplan und Matura-Vorbereitung

### Enthalten in diesem Release

- **Web-App** (`index.html`) — Module 1–8 von Entity-Grundlagen bis Konfiguration & Lifecycle
- **Maven-Übungen** (`Uebungen/`) — 5 didaktisch aufbauende Projekte als Ausgangsprojekte ohne JPA-Annotationen
- **Dokumentation** (`docs/`) — ergänzende Lernmaterialien
- **Public-ready Setup** — strukturierte `.gitignore`, private Professor-Materialien ausgeschlossen
